Seu textarea, agora um editor.

Uma linha de jQuery transforma o campo num editor completo. O HTML continua indo no envio do formulário, já limpo contra XSS.

Instalar a versão 1.1.0 Baixar o arquivo

O assistente de IA desta demonstração responde com um texto de exemplo. No seu site, ele usa o Gemini ou a OpenAI pelo ai-api.php.

O que o formulário recebe

Ao lado, o HTML que o formulário envia. Tudo o que entra passa pelo sanitizador, seja o que você digita, o que cola ou o que chega da IA. Os exemplos rodam no editor desta página.

O que vem pronto

  • Imagens

    Envie pelo botão, arraste o arquivo ou cole um print. Redimensione pela alça e alinhe pela barra da imagem; o upload vai para o seu servidor.

  • Tabelas

    Escolha o tamanho numa grade, inclua linhas e colunas pelo menu da célula e ande entre as células com Tab.

  • Fontes do Google

    O catálogo inteiro cabe no menu, com busca. Cada família só é baixada quando aparece na lista ou já está no texto.

  • Código-fonte

    Edite o HTML com realce e numeração de linhas. O que você muda no código volta para o editor já sanitizado.

  • Tema escuro

    Segue a classe .dark da sua página ou a opção theme. As cores são variáveis CSS que você ajusta.

  • Pelo teclado

    Alt+F10 leva à barra, as setas andam entre os botões e Ctrl+K abre o link. Leitores de tela anunciam menus e janelas.

Instalação em três trechos

  1. Primeiro, inclua o jQuery e o Weaver.

    <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/edersonfr/weaver-editor@v1.1.0/dist/weaver-editor.min.js"
        integrity="sha384-c7oOrLnhc5mQo12f2DljdvdQaiIwxCPiayKwrUFwT1x+GMGIye3R7D91P5y1U92N"
        crossorigin="anonymous"></script>
    > WysiwygEditor.VERSION '1.1.0'

  2. Depois, aponte para o seu textarea.

    $(function () {
  $('#artigo').weaver({ height: 400 });
});

  3. No envio, o HTML chega no campo de sempre.

    $html = $_POST['conteudo_html'];
// Limpo no navegador. No modo confiável, valide também no servidor.
